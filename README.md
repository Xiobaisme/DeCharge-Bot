# 🤖 DeCharge Auto-Clicker Dashboard (GitHub Edition)

Repositori ini berisi skrip otomasi berbasis **Playwright** yang berjalan di server **GitHub Actions**. Skrip ini dirancang untuk berinteraksi dengan link secara terjadwal dan dikendalikan sepenuhnya melalui **Bot Telegram**.

---

## 🛠️ Persiapan Awal (Prerequisites)

Sebelum menjalankan bot, pastikan Anda memiliki:
1. **Bot Telegram**: Buat melalui [@BotFather](https://t.me/botfather) untuk mendapatkan `TELE_TOKEN`.
2. **Chat ID**: Dapatkan ID akun Anda melalui [@userinfobot](https://t.me/userinfobot) untuk mengisi `CHAT_ID`.
3. **Proxy**: Layanan proxy (HTTP) beserta username dan password untuk keamanan navigasi.

---
